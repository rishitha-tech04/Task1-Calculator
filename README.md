# Python Calculator CLI App

## Description
A simple command-line calculator built using Python.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Repeats the menu until the user exits
- Handles division by zero
- Handles invalid menu choices

## Concepts Used
- Python functions
- `while` loop
- `if`, `elif`, and `else` conditions
- `input()` function

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run this command:

```bash
py calculator.py
